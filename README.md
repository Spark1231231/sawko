# sawko

Prototyp predpovede futbalových zápasov pre web [Stavková pravdepodobnosť](https://stavkova-pravdepodobnost.vercel.app).

Všetko je v priečinku [`prototype/`](prototype/README.md): rozbor modelu webu, matematika prototypu, iteračná
slučka s walk-forward backtestom, výsledky a ostré predpovede (`prototype/results/`).
